Smart Scheduler Data Model

The tables store only what people enter. Shift times, flags, rule violations, owed rest and fairness are computed when needed. Scroll sideways on narrow screens.

    COMPANY {
        uuid id PK
        text name
    }
    USER_ACCOUNT {
        uuid id PK
        uuid company_id FK
        citext email UK
        text auth_subject UK "Auth0 sub"
        text display_name
        boolean is_company_admin
    }
    TEAM {
        uuid id PK
        uuid company_id FK
        text name
        text timezone
        text municipal_holiday "MM-DD"
        int min_rest_between_shifts_min
        int max_consecutive_work_min
        int max_avg_weekly_work_min
        smallint avg_reference_weeks
        int min_weekly_rest_min
        smallint max_consecutive_nights
        int rest_after_night_run_min
    }
    TEAM_MEMBER {
        uuid id PK
        uuid team_id FK
        uuid user_id FK
        enum role "MANAGER or MEMBER"
        boolean works_shifts
        smallint fte_percent
        boolean active
    }
    SHIFT_TEMPLATE {
        uuid id PK
        uuid team_id FK
        text name
        time start_time
        time end_time
        boolean is_night
        smallint default_min_staff
        smallint default_max_staff
    }
    SCHEDULE_PERIOD {
        uuid id PK
        uuid team_id FK
        date start_date
        date end_date
        enum status "DRAFT, OPEN, CLOSED, PUBLISHED"
        timestamptz input_deadline
        int version
    }
    SHIFT_SLOT {
        uuid id PK
        uuid period_id FK
        uuid template_id FK
        date date
        smallint min_staff
        smallint max_staff
    }
    AVAILABILITY {
        uuid slot_id PK
        uuid team_member_id PK
        enum kind "AVAILABLE, IF_NEEDED"
        uuid entered_by FK
    }
    ASSIGNMENT {
        uuid slot_id PK
        uuid team_member_id PK
        enum source "ENGINE or MANUAL"
        text override_comment
        timestamptz confirmed_at
        timestamptz actual_start_at
        timestamptz actual_end_at
    }
    AUDIT_EVENT {
        bigserial id PK
        uuid company_id FK
        uuid actor_user_id FK
        text entity_type
        text action
        jsonb payload
    }

Computed when needed

  • Shift start, end and lengthSlot date + template times + team timezone, so daylight-saving nights are correct
  • Night, weekend, holidayTemplate flag, weekday, and Portuguese holidays calculated in code (including Easter-based ones)
  • Rule violations and unfilled-shift reasonsThe rule validator, run on demand
  • Owed compensatory restActual times that cut into minimum rest block the interval right after the work
  • Fairness stats and carry-overAssignments and availability from the last 3 periods
  • Fair-share targetShare of total required minutes, in proportion to each member's fte_percent
